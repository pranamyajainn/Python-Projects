# Python-Projects

Welcome to the **Python-Projects** repository! 🎉  
This repository is a collection of projects built as part of the **100 Days of Code** course by [Angela Yu](https://www.udemy.com/course/100-days-of-code/).

 📝 About the Course

The 100 Days of Code course by Angela Yu is an intensive bootcamp designed to teach Python programming from beginner to advanced levels. The course focuses on practical projects to help reinforce coding concepts and build a strong foundation in Python.

 🚀 Projects in This Repository

This repository contains various Python projects created during the course.
Each project explores unique programming concepts, APIs, GUIs, and more.

 💡 Key Learning Objectives

By working through these projects, you will:  
- Develop problem-solving skills.  
- Understand Python programming fundamentals.  
- Work with libraries, APIs, and frameworks.  
- Build real-world applications.
